### Key Takeaways
**Design Mindset**
- Agents are orchestrators, not autonomous entities — careful control and validation at each step
- Security-first: Identity management is critical for agent-executed actions
- Knowledge bases are the foundation of contextual agent responses

**Technical Architecture**
- AgentCore Gateway handles protocol translation and routing
- Runtime engine executes deterministic action sequences
- Cognito provides secure, scalable authentication for UI layers

**Applying to Work**
- Design agents with bounded action sets to minimize risk
- Implement proper audit logging for all agent operations
- Use structured knowledge bases to improve response consistency
