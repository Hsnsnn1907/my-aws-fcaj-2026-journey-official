Date & Time: 09:00, June 6, 2026

Location: Offline

### Event Objectives

The primary goal of this event was to provide a foundational understanding of cloud computing utilizing Amazon Web Services. It aimed to clarify the core structural differences between traditional virtual machines and modern containerization technologies. Furthermore, the session intended to showcase practical AWS tools and demonstrate how the cloud ecosystem can be leveraged to build and host live gaming applications directly on the cloud.

### Speakers

The main speaker for this session was Hung Gia, who shared his extensive technical knowledge and guided the attendees through practical cloud demonstrations.

### Key Highlights

The session delved deep into the architectural comparison between running applications on traditional virtual machines versus Docker containers. It thoroughly explained how containers share the host operating system kernel to achieve lightweight packaging and rapid deployments, eliminating the heavy hardware emulation overhead of virtual machines. Hung Gia introduced a variety of highly useful supporting tools within the AWS ecosystem designed to streamline the software development workflow, such as AWS CodePipeline and Amazon Elastic Container Registry. A particularly fascinating highlight was the live demonstration outlining the methodologies of using cloud-managed services like Amazon GameLift and DynamoDB to structure, deploy, and maintain a real-time gaming application directly on AWS with ultra-low latency.

### Key Takeaways

I learned that choosing between virtual machines and containers depends heavily on the specific system requirements for tight operating system isolation versus resource efficiency and scalability. Docker provides a significant deployment advantage for modern microservices due to its minimal footprint. Additionally, the event highlighted that AWS is not strictly limited to standard enterprise web applications but provides highly robust, scalable services perfectly suited for the demanding performance needs of the real-time gaming industry.

### Event Experience

Attending the Introduction to AWS event was incredibly engaging and immensely broadened my technical horizons. Listening to Hung Gia break down complex virtualization concepts into easily digestible explanations helped solidify my fundamental understanding of modern cloud deployment strategies. The practical and visual examples, especially the live gaming infrastructure implementation, made the theoretical cloud concepts feel tangible and highly inspiring. This gathering served as a phenomenal opportunity to explore modern tools that I can seamlessly integrate into my own backend microservice pipelines.
