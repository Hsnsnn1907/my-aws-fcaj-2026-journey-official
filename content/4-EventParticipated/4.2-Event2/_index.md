Event Name: GenAI-powered App-DB Modernization Workshop & Meetup

Date & Time: 09:00, June 13, 2026

Location: 26th Floor, Bitexco Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City

Role: Attendee

### Event Objectives
- Introduce techniques for application and database modernization using generative AI tools
- Discuss strategies for optimizing microservices and serverless architectures
- Present real-world case studies of migrations from monoliths to cloud-native systems
- Provide insights into effective database querying using GraphRAG and advanced indexing
- Explain the role of AWS Bedrock, Lambda, and DynamoDB in modern AI application design

### Speakers
- Hiếu Nghị – DevOps Engineer
- Kiên và Thọ – Solutions Architects
- Anh Hoàng Trọng – Senior AWS Specialist
- Anh Đạt và anh Cường – Database & AI Engineers

### Key Highlights
**Application & Database Modernization**
- Modernizing database architectures to support AI-driven application payloads.
- Breaking down monolith legacy structures into event-driven serverless architectures to reduce operational overhead.
- Strategies for database migration without service downtime.

**Generative AI Integration**
- Deploying large language models (LLMs) referencing enterprise databases using AWS Bedrock.
- Implementing GraphRAG to significantly enrich structural context and domain metrics for smarter AI outputs.
- Running serverless AI workflows utilizing AWS Lambda orchestrations and API Gateway endpoints.

**Microservices Optimization**
- Restructuring API layers to leverage asynchronous message queues such as RabbitMQ.
- Optimizing database interaction frameworks using modern tools like Prisma and Qdrant vector databases.
- Hands-on walkthroughs explaining microservice boundary design and bounded context mapping.

### Key Takeaways
**Design Mindset**
- Business-driven architecture: Infrastructure must follow concrete business rules rather than speculative technology choices.
- Asynchronous-first approach: Reduce tight coupling across microservices to maximize fault tolerance.

**Technical Architecture**
- Use serverless layers (AWS Lambda) for scalable, pay-as-you-go backend logic.
- Integrate vector databases (Qdrant) and GraphRAG to build contextual AI agents.
- Optimize database execution plans using efficient query parsing and indexing.

**Applying to Work**
- Apply asynchronous patterns to current microservices to resolve API blockages.
- Pilot AWS Bedrock and Lambda functions for lightweight AI-driven features.
- Restructure database access schemas to leverage Prisma multi-schema features.
